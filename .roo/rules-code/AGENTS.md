# Code Mode Rules

- `src/ifdata.rs` is generated by the `a2ml_specification!` macro. Never edit manually.
- `UpdateSummary` fields track per-object-type counts. When adding update logic, ensure counts go to the correct field (past bug: axis_pts counts were added to measurement counters).
- `RecordLayoutInfo::build(module)` must be called before update operations - it caches layout lookups.
- `make_symbol_link_string()` in `src/update/mod.rs` handles the Vector-style `{Function:...}{CompileUnit:...}{Namespace:...}` encoding. Always use it rather than manual string building.
- `set_matrix_dim()` behavior differs based on A2L version: pre-1.70 requires exactly 3 dimensions, 1.70+ allows any count.
- The `INSERT_ARGGROUP` in CLI args must list all insert-related arg IDs. Missing entries cause `--target-group` to silently not require them.
